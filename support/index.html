基本操作

アプリには次の主な画面があります。

  • 今日 … その日の掃除一覧と進捗
  • すべて … 掃除メニューの一覧・追加・編集
  • カレンダー … 月ごとの予定と実績
  • 振り返り … 期間ごとの実施状況
  • 設定 … 通知、メンバー、データの書き出し・削除など

掃除メニューの追加

  1. 「すべて」画面を開きます。
  2. 追加（＋）からメニュー名と周期（頻度）を設定します。
  3. 必要に応じてカテゴリやメモを付けます。

周期は、日ごと・曜日・隔週・毎月など、暮らしに合わせて選べます。

完了・延期・スキップの違い

  • 完了 … 実施したことを記録します。次回予定が更新されます。
  • 1日延期 … 予定を1日先へずらします（実施したことにはなりません）。
  • スキップ … その回を飛ばしたことを記録します。完了とは区別されます。

同一端末のメンバー

設定から、同じ端末で使うメンバー（例: 自分・パートナー）を登録できます。担当と、実際に行った人を分けて記録できます。

これは端末内の管理機能です。別の Apple ID 同士の自動同期とは異なります。

通知設定

  1. 「設定」→「掃除の通知」をオンにします。
  2. 通知時刻を選びます。
  3. 初回は iOS の許可ダイアログが表示されます。拒否しても、アプリの主要機能は使えます。

予定日の通知時刻に、その日の掃除をまとめてお知らせします。

データのバックアップと復元

  1. 「設定」からデータを JSON ファイルとして書き出します。
  2. 復元したいときは、同じ設定画面からファイルを取り込みます。
  3. 取り込み前に内容のプレビューがあり、実行は明示操作のときだけ行われます。

書き出したファイルの保管場所は、お客様ご自身で管理してください（Files、メールなど）。

データ削除

「設定」の「すべてのデータを削除」で、端末内の掃除データや設定状態を削除できます。この操作は取り消せません。必要な場合は事前に書き出してください。

アプリ自体を端末から削除した場合も、端末内データは削除されます。

よくある質問

アカウント登録は必要ですか？

通常の利用にアカウント登録は不要です。起動後すぐに使えます。

データはどこに保存されますか？

原則としてお客様の端末内に保存されます。運営者のサーバへ自動送信する仕組みはありません。

完了回数は公平さの判定に使われますか？

いいえ。アプリは完了回数を家事の公平さの断定には使いません。

通知をオフにしても使えますか？

はい。通知は任意です。オフでも予定の確認や記録はできます。

対応端末は？

iPhone（iOS 17 以降）向けです。

別の iPhone に引っ越すには？

設定から JSON を書き出し、新しい端末のアプリで取り込む方法があります。
